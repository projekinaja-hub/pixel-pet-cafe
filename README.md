# Pixel Pet Café ☕🐱

A cozy pixel-art idle game that lives in your macOS menu bar. Animal baristas
run a little café and earn coins while you work — and while your Mac sleeps.

The menu bar shows Mocha the cat (she blinks and sips coffee) next to your coin
count. Click it to open the café: an animated SpriteKit scene on top, and the
game below in four tabs — **Café** (equipment), **Staff**, **Recipes**, and
**Renovate** (prestige).

## Gameplay

- **Earn** — staff generate coins every second: `Σ(level × rate) × equipment ×
  recipes × (1 + 0.1 × ⭐)`.
- **Hire** — six animal staff unlock as you earn: Mocha 🐱 (barista), Biscuit 🐶
  (waiter), Poppy 🐰 (pâtissier), Juno 🦊 (cashier), Bo 🐻 (roaster), and Earl 🦉,
  whose night shift extends your offline-earnings cap (+1h per level, 8h base).
- **Recipes** — unlock automatically at lifetime-coin milestones; each is a
  permanent income multiplier for the run.
- **Golden tips** — while the panel is open, a sparkling coin appears every few
  minutes; click it for 10 minutes of income.
- **Renovate** — past 1M coins earned in a run, reset the café for permanent
  ⭐ stars (+10% income each). The café decor visibly upgrades with stars.
- **Offline earnings** — the café keeps earning while the app is closed or the
  Mac sleeps, up to the cap; a toast shows the haul when you return.

## Build & run

```bash
swift run                    # run directly (dev)
./tools/test.sh              # run unit tests (wraps swift test for this machine)
./tools/make_app.sh          # build dist/PixelPetCafe.app (menu bar app, no dock icon)
open dist/PixelPetCafe.app
```

Launch-at-login (right-click menu) works when running from the `.app` bundle.

## Project layout

- `Sources/PixelPetCafe/Core/` — pure, unit-tested game logic (`GameState`,
  `EconomyEngine`, `Catalog`, `Persistence`, number formatting).
- `Sources/PixelPetCafe/Scene/` — the SpriteKit café scene (paused whenever the
  popover is closed; the idle app uses ~0% CPU).
- `Sources/PixelPetCafe/App/` — menu bar status item, popover, game controller
  (1s tick, 30s autosave, sleep/wake handling).
- `Sources/PixelPetCafe/UI/` — SwiftUI panel views.
- `tools/generate_sprites.py` — all pixel art is generated by this stdlib-only
  Python script (edit the pixel grids, re-run, rebuild).

Saves live at `~/Library/Application Support/PixelPetCafe/save.json` (atomic
writes; corrupt saves are backed up aside, never lost).

Design doc: `docs/superpowers/specs/2026-07-06-pixel-pet-cafe-design.md`.

Dev hooks: `PPC_OPEN=1` opens the popover on launch; `PPC_SNAPSHOT=/path.png` /
`PPC_SCENESHOT=/path.png` render the panel / scene to a PNG and exit.
